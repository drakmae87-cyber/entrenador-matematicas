# Entrenador educativo — PoC interactiva preliminar

Este repositorio contiene una **prueba de concepto (PoC) interactiva y preliminar**, creada con fines de exploración y demostración. Es una maqueta educativa en desarrollo; no representa un producto terminado ni un sistema profesional validado.

## Alcance de la demostración

- Actividades educativas de matemáticas y visualizaciones interactivas.
- Una sección de enfermería únicamente como material educativo/maqueta visual.
- Aplicación estática de una sola página (`index.html`), sin servidor propio ni base de datos remota.
- Algunas preferencias, puntuaciones y apuntes pueden guardarse en el almacenamiento local del navegador.

## Aviso importante

La sección de enfermería **no sustituye protocolos institucionales vigentes, formación profesional, juicio clínico ni supervisión**. No debe usarse para tomar decisiones clínicas, calcular o administrar tratamientos, ni atender pacientes. El contenido es demostrativo y puede estar incompleto o no corresponder a las normas aplicables.

No ingreses información personal, identificable ni datos reales de pacientes. Los datos guardados en el navegador permanecen en ese dispositivo y no son un sistema seguro de historia clínica o almacenamiento institucional.

## Publicación y tráfico

La aplicación estática está pensada para una demostración ligera. Etiquetarla como PoC o incluir este aviso **no restringe el acceso, no limita las visitas y no garantiza un límite de tráfico**. Al publicar el sitio mediante GitHub Pages, la página será accesible públicamente; GitHub controla la infraestructura y aplica sus propios límites de uso.

## Uso local

Abre `index.html` en un navegador moderno. No se requiere instalar dependencias ni ejecutar un backend.

## Estado

Proyecto experimental en evolución. Las funciones, los contenidos y las visualizaciones pueden cambiar.
